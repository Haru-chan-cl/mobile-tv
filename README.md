# mobile TV

App para ver canales de TV abiertos, noticias y ciencia en vivo, usando solo fuentes oficiales y públicas. El plan completo está en `tasks/plan.md`.

## Cómo abrir la app en tu computador

Necesitas tener Node.js instalado.

1. Abre una terminal dentro de la carpeta del proyecto.
2. Escribe `npx serve .` y presiona Enter (la primera vez pide confirmar la instalación: responde `y`).
3. Abre en el navegador la dirección que aparece en la terminal, normalmente `http://localhost:3000`.

Para detener el servidor, presiona `Ctrl + C` en la terminal.

## Cómo instalar

Para instalar la app en un celular (Android o iPhone), abre la guía paso a paso:

https://haru-chan-cl.github.io/mobile-tv/instalar.html

La guía explica cómo instalar el navegador Brave, abrir la app en él, dejarlo como navegador predeterminado y agregar la app a la pantalla de inicio. Solo usa enlaces oficiales: este repositorio no guarda instaladores ni archivos APK.
