# Tipografías

Las tipografías viven dentro del proyecto para que la app no llame a servidores externos (Google Fonts).
Son solo el subconjunto `latin`, que cubre el español (ñ, tildes, ¿, ¡).

| Archivo | Tipografía | Peso |
|---|---|---|
| `barlow-condensed-500.woff2` | Barlow Condensed | 500 |
| `barlow-condensed-600.woff2` | Barlow Condensed | 600 |
| `noto-sans-jp-variable.woff2` | Noto Sans JP (variable) | 400 a 900 |

Origen: archivos publicados por Google Fonts (fonts.gstatic.com), descargados una sola vez.
Licencia: SIL Open Font License 1.1. El texto completo está en `OFL-barlow-condensed.txt` y `OFL-noto-sans-jp.txt`.
Se declaran con `@font-face` en `design/tokens.css`.
